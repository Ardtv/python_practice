# Менеджер паролей

Консольный менеджер паролей с шифрованием. Лабораторная работа 1, трек DevOps, тема Б1.

## Возможности

- вход по мастер-паролю, хранится только проверочный хэш (PBKDF2-HMAC-SHA256, 600 000 итераций, случайная соль);
- записи зашифрованы (Fernet: AES-128-CBC + HMAC-SHA256);
- команды `add`, `list`, `get`, `edit`, `delete`;
- скрытый ввод паролей, `get` после подтверждения мастер-паролем, копирование в буфер с автоочисткой через 20 секунд;
- генератор паролей;
- несколько аккаунтов на один сервис.

## Установка

Через `pip` и виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Или через `uv` — он сам создаст окружение и поставит зависимости при первом запуске:

```bash
uv run python password_manager.py --unlock
```

## Запуск

| Команда | Что делает |
| --- | --- |
| `python password_manager.py --init` | создать хранилище и мастер-пароль |
| `python password_manager.py --unlock` | войти в хранилище и открыть меню команд |
| `python password_manager.py` | без флагов: создать хранилище, если его нет, иначе войти |
| `python password_manager.py --generate` | сгенерировать пароль без входа в хранилище |
| `python password_manager.py --generate --length 16 --no-symbols` | то же с параметрами: длина 16, без спецсимволов |
| `uv run python password_manager.py --unlock` | запуск через `uv` |
| `passman --help` | справка по аргументам (команда доступна после `pip install -e .`) |

### Команды меню

После входа появляется приглашение `passman>`:

- `add <сервис>` — добавить запись: логин, пароль (сгенерировать или ввести вручную), заметка;
- `list` — список записей без паролей;
- `get <сервис>` — после подтверждения мастер-паролем скопировать пароль в буфер обмена (очищается через 20 секунд), по желанию показать на экране;
- `edit <сервис>` — изменить логин, пароль или заметку;
- `delete <сервис>` — удалить запись с подтверждением;
- `help` — список команд, `help <команда>` — справка по команде;
- `exit` — выход (также Ctrl+D).

Если у сервиса несколько аккаунтов, программа покажет список логинов и попросит выбрать номер.

## Безопасность

- Мастер-пароль нигде не хранится. Из него через PBKDF2-HMAC-SHA256 (600 000 итераций, случайная соль 16 байт) получается ключ, в файле лежит только SHA-256 от ключа для проверки.
- Записи шифруются Fernet (AES-128-CBC + HMAC-SHA256). Если файл подменить или испортить, программа это заметит.
- В `vault.dat` открыто лежат только версия формата, название KDF, число итераций, соль и проверочный хэш. Сервисы, логины и пароли зашифрованы.
- Файл пишется атомарно (временный файл + `os.replace`) с правами 600, только для владельца.
- Пароли не выводятся на экран: ввод через `getpass`, `get` копирует в буфер, который очищается через 20 секунд.

От чего программа не защищает: вирус или кейлоггер на компьютере, утечка самого мастер-пароля. Забытый мастер-пароль восстановить нельзя.

## Известные ограничения

- Очистка буфера ввода через `termios` работает только на macOS и Linux.
- Если печатать во время паузы после неверного пароля, символы видны на экране (в пароль они не попадают).
- Заметки выводятся открытым текстом, секреты в них хранить не стоит.
- `--generate` печатает пароль на экран: программа сразу завершается, и автоочистка буфера не успела бы сработать.
